Deterministic Node 22 TypeScript entry that writes the office printer's dry, deadpan comeback line (1–240 UTF-8 characters) to `/output/entry.txt` for make.fun's “The Printer Finally Answers” bounty.

## Run it

```sh
node main.ts
```

## Verify it

```sh
node scripts/verify.ts
```

Runs `main.ts` twice into temporary files and checks determinism, UTF-8, single-line output, and the 1..240 character limit.
